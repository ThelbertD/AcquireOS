## How to fill this in

Every section has an instruction line in italics saying what a good answer looks like. Answer in
the client's own words. Do not tidy the language into marketing prose — the point of this
document is to capture how the client and their buyers actually speak, and polished input
produces generic output.

**Blank sections are blockers, not gaps.** An empty proof points section produces copy with
invented proof, which is a legal exposure. If the client cannot answer a required section, that
is a finding to raise before writing begins, not something to work around.

Sections marked **REQUIRED** block the build. Sections marked *optional* improve the output.

rough band, so copy does not aim a message at someone who could never afford it or write down
